# 术语表

> 更新日期：2026-10-15。
>
> 本文统一叫法。规则本身在各篇正文，本表只防止同一种东西写出两个名字。缩写可以出现在对供应商的口头说明里，正文优先用中文。
>
> WMS仓库的文档故意不用PO、ASN。门户要和工厂沟通，允许在括号里写缩写，但单据名以中文为准。

| 术语 | 本仓库的叫法 | 不要写成 |
| --- | --- | --- |
| 采购订单 | SRM创建并审核后推送ERP的成品采购订单。口头可称PO。ERP侧只读。变更只能在SRM发起 | 在ERP新建的第二张订单。允许改哪些字段见【待确认-03】 |
| 接单确认 | 供应商对采购订单的确认或拒绝，时限24小时 | 超时自动确认。自动与否、能否带条件接受，见【待确认-19】 |
| 交期建议 | 供应商提出的新交期。采购在SRM接受后，由SRM发起变更并推送ERP，ERP不单独改期 | 只在ERP调整交期；也不是改价 |
| 承诺交期 | 变更已经推送成功之后，两边当前有效的交货日期 | 把尚未推送成功的建议日期当成承诺交期。自动关闭由谁发起，见【待确认-04】 |
| 订单变更 | 只能在SRM发起，再推送到只读的ERP订单 | ERP变更单；也不是「完全不做变更」。字段范围见【待确认-03】 |
| 齐套 | 关键物料是否备齐的节点记录 | MRP齐套、BOM展开、车间工序报工 |
| 半成品备料 | 阶段5的做法：平时备着通用电芯和外壳，不组装成成品，爆单后再组装 | 强盛的原材料库存。记不记库存见【待确认-11】 |
| 委外供料 | 品牌把自行采购的物料发给代工厂。强盛是否这样做，见【待确认-12】 | 已经上线的业务 |
| 发货单 | 供应商对一次发货的预告，包含数量、批次和箱数。口头可称ASN。它推动ERP生成收货通知 | 采购收货通知单。通知单在ERP，是仓库的指令 |
| 采购收货通知单 | ERP的执行指令，前缀CGSHTZ。由ERP下发给WMS，仓库只执行这一张 | ASN、送货通知（当作另一张指令时）；也不是采购在ERP里代录的现行规则 |
| 预约送货 | 到哪个仓、哪一天的哪个时段、车牌和件数 | 收货过账 |
| 箱码 | 一箱一个的物流单元标识，扫码后查回采购订单、SKU、批次和数量 | 库存对象。门户不建箱库存 |
| 箱唛 | 贴在外箱上的标识。FBA和电商仓平台往往有自己的箱唛 | 与强盛箱码混成同一个码。平台是否还要贴强盛箱码，见【待确认-22】 |
| 源头贴码 | 供应商出厂前贴好标准外箱码，到仓直接扫 | 库内二次贴标 |
| 代录 | 采购代替尚未上线的供应商，在SRM确认或登记发货，并留下人和依据 | 在ERP另建采购订单；事后无痕补单 |
| 推送 | 审核通过的SRM采购订单送到ERP，一张对一张 | 失败后改单号再推成第二张。重试参数见【待确认-06】 |
| 对账单 | 按期间和供应商，以ERP已审核入库、采退为基准的确认结果 | 应付单 |
| 开票申请 | 对账确认之后，算出应开金额和税额，交给供应商开票 | 税票本身，也不是应付单 |
| 税票 / 数电票 | 2024年12月1日起全国推广的数字化电子发票，号码20位，无发票代码 | 发票代码作为必填；把影像上传当成已经抵扣 |
| 红字确认单 | 购买方已做用途确认或入账确认时，开红字发票前的《红字发票信息确认单》。72小时未确认则作废 | 贷项通知单、Ariba credit memo |
| 三单匹配 | 采购订单价格、实际收货数量和发票之间的核对 | 金蝶里的应付核销。核销在金蝶，门户只做预校验 |
| 暂估应付 | 已入库、发票未到时，在金蝶按入库金额暂估的应付 | 门户里的一种单据 |
| 参股代工厂 | 2019年参股的3家核心厂：线材、充电头、充电宝 | 关联方。是否构成重大影响，见【待确认-26】 |
| 联营企业 | 只按《企业会计准则第36号》使用：投资方能施加重大影响的被投资单位 | 联营门店。本仓库没有联营门店 |
| 直营门店 | 强盛自己经营的体验店 | 供应商的送货对象。门店不向工厂下单 |
| 加盟门店 | 加盟合作的体验店，模式为代销，售出前货权归强盛 | 联营、扣点、商场对账 |
| 驻厂QC / 驻厂工程师 | 阶段4起派在代工厂的品质或工程人员，按节点抽检 | 工厂的生产调度 |
| 金蝶 | 金蝶云·星空，法定核算、应付和总账 | 业务采购订单的创建入口 |
| 主数据平台 | 阶段5统一定义SKU、客户和组织的源头 | 供应商主数据的已确认源头。供应商归属见【待确认-13】 |
| Code-Name | 编码加一个空格再加名称的展示方式 | 把名称拼进单号或接口主键 |
| SSCC | GB/T 18127-2009规定的18位系列货运包装箱代码 | 强盛已经在用的箱码。有没有厂商识别代码，见【待确认-23】 |

ERP收货执行、入库结果和价格精度仍以ERP仓库为准。采购订单的创建和变更发起以本仓库为准。ERP旧文尚未改的位置见[待对齐事项](11.待对齐事项.md)。
