# 强盛科技自研 SRM 项目

这是基于「强盛科技」虚拟企业的供应商协同门户设计仓库。公司自己做品牌和渠道，生产放在代工厂。采购员的主工作台在这里：采购订单在SRM创建并审核，审核通过后推送到ERP。ERP接收订单并只读持有，负责库存、在途、成本和业财，再把收货通知下发给WMS。法定核算仍在金蝶。

> 强盛科技的时间、规模和业务数据都是课程演练用的虚拟内容，不代表任何真实企业。
